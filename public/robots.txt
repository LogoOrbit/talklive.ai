# Deliberately NOT disallowed:
#
#   /call and /chat  — the live app shells. Both serve <meta name="robots"
#     content="noindex">, which is the correct tool for keeping a page out of
#     the index. Adding a Disallow on top would be counterproductive: a blocked
#     URL is a URL Google cannot fetch, so it never reads the noindex, and an
#     externally-linked blocked URL can still be indexed with no content at all.
#
#   ?utm_ tagged URLs — every CTA on the landing pages carries campaign
#     parameters. They all canonicalise to the clean URL, and blocking them
#     would stop crawlers reading that canonical tag, which is what actually
#     consolidates them. Let them be crawled and discarded.
